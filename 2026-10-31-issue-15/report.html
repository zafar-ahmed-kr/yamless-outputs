Issue #15 — .NET / C# Runtime Support

Problem

YAMLess returned runtime: unknown, shape: unknown, no dependencies, and secrets: [] on .NET repos. Two root causes: 1. No NuGet / .csproj parser 2. _find_dockerfile only checked the repo root — .NET solutions conventionally put Dockerfile inside the API project subdirectory
