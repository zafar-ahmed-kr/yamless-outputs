Summary

The feature/golden-profiles branch introduces a comprehensive library of 36 golden configuration profiles for Azure, AWS, and Kubernetes resources, along with governance gate templates, a cost estimator, pod disruption budget manifests, HPA stabilization enhancements, and backend Terraform templates.

This merge significantly expands YAMLess's ability to enforce environment-aware infrastructure standards across all four supported renderers: Container Apps, AKS, ECS, and EKS. It also expands the core modules (golden.py, profile.py, gap_filler.py, cli.py) by approximately 370 lines and adds 6 new tests to test_golden.py.

New Features

Governance Gate Templates (governance.tf.j2)

Added for all four renderers, each containing Sentinel/OPA policy stubs and tagging enforcement:

  • Container Apps — Sentinel/OPA stubs enforcing tagging, SKU constraints, and allowed resource types for Azure
  • AKS — Azure Policy assignments at cluster scope with deny effects for non-compliant workloads
  • ECS — AWS Config rules and Service Control Policy stubs covering ECS task IAM boundaries
  • EKS — OPA Gatekeeper constraint templates enforcing namespace labels and pod security standards

All templates enforce the required tags: environment, team, cost-centre, managed-by.

Cost Estimator (src/yamless/cost_estimator.py — 628 lines)

  • Looks up unit pricing for Azure and AWS resource SKUs from golden profiles
  • Aggregates estimated monthly costs per environment (dev vs production)
  • Outputs a cost summary table alongside the rendered Terraform
  • Integrates with the CLI via the new yamless estimate subcommand

PodDisruptionBudget Manifests (pdb.yaml.j2)

  • Added for both AKS and EKS renderers
  • Minimum available replicas derived from the golden profile min_replicas field
  • Selector labels aligned with the deployment's app label
  • Rendered alongside existing deployment and HPA manifests

HPA Stabilization Windows & Topology Spread Constraints

  • scaleDown.stabilizationWindowSeconds (default 300 s) — prevents replica flapping
  • scaleUp.stabilizationWindowSeconds (default 60 s) — faster scale-out response
  • Topology spread constraints ensure pods spread across availability zones with whenUnsatisfiable: DoNotSchedule

Backend Terraform (backend.tf.j2) and terraform.tfvars.example.j2

  • Azure renderers (Container Apps, AKS): Azure Blob Storage backend with key derived from app slug and environment
  • AWS renderers (ECS, EKS): S3 backend with DynamoDB locking table
  • terraform.tfvars.example.j2 provides documented variable file template for each renderer
